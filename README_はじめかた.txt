FOUNDER LAB セットアップ

これはスマートフォン向けのWebアプリです。
ホーム画面追加・オフライン起動にはHTTPSでの公開が必要です。

公開方法の例：
1. GitHubアカウントで新しいPublicリポジトリを作成
2. このZIPの中身（index.html / manifest.webmanifest / sw.js / icon.svg）をアップロード
3. Settings → Pages → Deploy from a branch → main / root → Save
4. 表示されたHTTPS URLをAndroidのChromeで開く
5. Chrome右上の ⋮ →「アプリをインストール」または「ホーム画面に追加」

注意：
- このZIPは完成版の第一段階です。365日分の個別教材をすべて詳細執筆した状態ではなく、12か月の学習ロードマップと日々の学習画面の土台を実装しています。
- 学習進捗・メモは利用中のブラウザ内に保存されます。別端末への同期やアカウント機能はまだありません。
- 公開作業にはGitHub等のアカウント操作が必要です。パスワードは誰にも共有しないでください。
